# Тестове за парамедици (Streamlit)

Упражнения по 10 раздела (266 въпроса) и пробен изпит по анатомия, ДТПА (Заповед РД-01-326/05.06.2023) и Наредба № 3/2017 „Спешна медицина“.

## Локално стартиране
```
pip install -r requirements.txt
streamlit run app.py
```

## Деплой в Streamlit Community Cloud
1. Качете папката в GitHub хранилище (app.py, questions.json, requirements.txt, .streamlit/config.toml).
2. На share.streamlit.io → **Create app** → изберете хранилището, клон `main`, файл `app.py` → **Deploy**.

## Добавяне на въпроси
Отворете `questions.json` и добавете в масива `questions` на съответния раздел:
```json
{"question": "Текст на въпроса?",
 "options": ["Отговор 1", "Отговор 2", "Отговор 3", "Отговор 4"],
 "answer": 0,
 "explanation": "Кратко обяснение.",
 "source": "Наредба № ... , чл. ..."}
```
`answer` е номерът на верния отговор, броено от 0. Отговорите се разбъркват автоматично.
Нов раздел се добавя като нов обект с `id`, `n`, `title`, `desc` и `questions`.

В страничната лента изберете колко въпроса да има всяко упражнение (10–25 или всички) – при всеки опит се теглят различни случайни въпроси.

Забележка: най-добрите резултати се пазят само за текущата сесия в браузъра.
