# Тестове за парамедици (Streamlit)

Упражнения по 10 раздела (500 въпроса) и пробен изпит по анатомия, ДТПА (Заповед РД-01-326/05.06.2023) и Наредба № 3/2017 „Спешна медицина“.

## Локално стартиране
```
pip install -r requirements.txt
streamlit run app.py
```

## Деплой в Streamlit Community Cloud
1. Качете папката в GitHub хранилище (app.py, questions.json, requirements.txt, .streamlit/config.toml).
2. На share.streamlit.io → **Create app** → изберете хранилището, клон `main`, файл `app.py` → **Deploy**.

## Добавяне на въпроси
Отворете `questions.json` и добавете в масива `questions` на съответния раздел:
```json
{"question": "Текст на въпроса?",
 "options": ["Отговор 1", "Отговор 2", "Отговор 3", "Отговор 4"],
 "answer": 0,
 "explanation": "Кратко обяснение.",
 "source": "Наредба № ... , чл. ..."}
```
`answer` е номерът на верния отговор, броено от 0.

### Въпрос с картинка
Сложете картинката в папка `images/` и добавете поле `"image"`:
```json
{"question": "Какъв е ритъмът?",
 "image": "images/ecg_vf.png",
 "options": ["Камерно мъждене", "Асистолия", "Torsade de pointes", "Предсърдно мъждене"],
 "answer": 0,
 "explanation": "...",
 "source": "..."}
```
### Въпрос „Изчисли“ (въвежда се число)
```json
{"type": "calc",
 "question": "Пациент 80 кг с 30% изгаряне. Колко ml за първите 8 часа по Паркланд?",
 "value": 4800, "tolerance": 0, "unit": "ml",
 "explanation": "4 × 80 × 30 = 9600 ml; половината за 8 ч.",
 "source": "ДТПА, 1.34"}
```
`tolerance` е допустимото отклонение (напр. 0.05 за шоков индекс). Десетичните числа се пишат с точка: `0.18`.

### Въпрос „Подреди“
```json
{"type": "order",
 "question": "Подредете стъпките на първичната оценка ABCDE.",
 "items": ["Дихателни пътища (A)", "Дишане (B)", "Циркулация (C)", "Неврологичен статус (D)", "Експозиция (E)"],
 "explanation": "...", "source": "..."}
```
`items` се пишат в ПРАВИЛНИЯ ред – приложението ги разбърква само.

### Въпрос „Посочи на картинката“
```json
{"type": "point",
 "question": "Посочете основното място за иглена декомпресия вдясно.",
 "image": "images/body_front.png",
 "targets": [[272, 277, 18]],
 "target_label": "2-ро междуребрие по медиоклавикуларната линия вдясно",
 "explanation": "...", "source": "..."}
```
`targets` са кръгове `[x, y, радиус]` в пиксели на оригиналната картинка (body_front.png е 700 × 1080). Може да има повече от една правилна зона (напр. лява и дясна страна). Изисква пакета `streamlit-image-coordinates` (вече е в requirements.txt).

ЕКГ записите в `images/` са схематични (генерирани за учебни цели; II отвеждане, 25 mm/s, 10 mm/mV). Отговорите се разбъркват автоматично.
Нов раздел се добавя като нов обект с `id`, `n`, `title`, `desc` и `questions`.

В страничната лента изберете колко въпроса да има всяко упражнение (10–25 или всички) – при всеки опит се теглят различни случайни въпроси.

Забележка: най-добрите резултати се пазят само за текущата сесия в браузъра.
